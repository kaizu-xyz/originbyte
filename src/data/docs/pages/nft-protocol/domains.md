# Domains

As previously mentioned, domains are `structs` that are added to either `NFT` or `Collection` objects. They essentially add new behaviour and data to each NFT or to the whole Collection itself.

We currently have the following data-driven domain:

- [DisplayInfo](/docs/nft-protocol/domains/data-driven/displayinfo)
- [Attributes](/docs/nft-protocol/domains/data-driven/attributes)
- [Creators](/docs/nft-protocol/domains/data-driven/creators)
- [Supply](/docs/nft-protocol/domains/data-driven/supply)
- [Tags](/docs/nft-protocol/domains/data-driven/tags)
- [Svg](/docs/nft-protocol/domains/data-driven/svg)

And have specialised domains that inject logic into the NFT collection, such as:

- Composability
- Plugins
