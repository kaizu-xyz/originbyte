# Standards

As previously mentioned, domains are objects that are added to either `NFT` or `Collection` objects. They essentially add new behaviour and data to each NFT or to the whole Collection itself.

We currently have the following domain standards:

- [Display](/docs/nft-protocol/domains/data-driven/displayinfo)
- [Tags](/docs/nft-protocol/domains/data-driven/tags)
- [Creators](/docs/nft-protocol/domains/data-driven/creators)
- [Flyweight](/docs/nft-protocol/standards/loose-nfts)
- [Royalties](/docs/nft-protocol/royalty)
