# Tags

OriginByte's tag system allows for Wallets to organise their NFT display by categories. Wallets can query NFTs and check their `Tags` to figure out what the business domain of each NFT is.

![](https://2297996727-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FSTnJXhf5rlE9fHcRm1AL%2Fuploads%2Fc3fEzuhIvB7s91VJasnx%2FWood-Hand.png?alt=media&token=a1b425f2-77e8-4720-8871-b7d0a9ca9463)Example wallet display

Currently, we offer the following Tags:

- Art
- ProfilePicture
- Collectible
- GameAsset
- TokenisedAsset
- Tickers
- Ticker
- DomainName
- Music
- Video
- Ticket
- License
