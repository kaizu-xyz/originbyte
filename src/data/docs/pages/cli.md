# CLI

[suivm](https://github.com/Origin-Byte/suivm) is OriginByte's Sui version manager — a command-line tool for pinning and switching Sui CLI versions, in the same spirit as nvm for Node.js.

```bash
cargo install suivm
suivm use <version>
```

Pin a Sui CLI per project, hop between testnet and mainnet toolchains, and stop fighting a global install.
